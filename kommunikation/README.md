# Kommunikation-Plugin

Dieses Plugin enthält Skills rund um Präsentation, Storytelling und Wissenstransfer – also alles, was hilft, Inhalte für ein Publikum aufzubereiten.

## Installation

```bash
# Als Plugin laden (einmalig pro Session oder global konfigurieren)
claude --plugin-dir /pfad/zu/claude-skill-lib/kommunikation
```

## Enthaltene Skills

### `/kommunikation:effective-presentation-slides`

Wendet evidenzbasierte Prinzipien auf Folienpräsentationen an – von der ersten Gliederung bis zum finalen Review.

**Kernprinzipien:**
- Eine Idee pro Folie
- Titel formuliert das Fazit, nicht das Thema
- Zeigen statt beschreiben (Picture Superiority Effect, Dual-Coding-Theorie)
- Cognitive Load minimieren: kein Text, den das Publikum lesen muss, während es zuhört

Quellen: Naegle 2021, Mayer 2001, Paivio 1971/1986, Medina 2008
